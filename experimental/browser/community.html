Publish a SingulaX Project 🚀

    
Choose a SingulaX source or .sglxproj file. Publishing creates a public GitHub repository so the project can appear in the Community tabs. Your GitHub token is used only for this publish action and is not saved.

    

    

    

    

    
The token needs permission to create public repositories and write repository contents. For safety, it stays in memory and is cleared after publishing.
