# Singulax Studio Web

This is the browser-only Singulax Studio. Open `index.html` directly in a modern browser. It does **not** require Python, Node.js, a local server, or any other runtime installation.

## Features
- `.sglx` code editor
- block editor
- browser runtime for core Singulax control flow
- `if / elseif / else / end`
- `while`, `forever`, `for`, `repeat`
- `local`, `let`, `var`
- functions
- keyboard, pointer/touch and mouse-style game input
- canvas drawing
- local project saving
- `.sglxproj.zip` project export/import

For maximum compatibility, use a current Safari, Chrome, Edge, or Firefox. Some advanced language features from the Python reference interpreter are still being ported to the browser runtime.
