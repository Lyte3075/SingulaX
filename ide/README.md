# Singulax Studio

A dependency-free local web IDE for Singulax. Run `python3 ide/server.py` from the Singulax folder, then open `http://127.0.0.1:8765/`.

Features: `.sglx` code editor, starter block editor, project save/load, ZIP export/import, console output, HTML canvas preview, and live keyboard/mouse input bridged to Singulax (`key_down`, `mouse_x`, `mouse_y`, `mouse_down`, `mouse_clicked`).
